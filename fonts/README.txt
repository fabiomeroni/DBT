Charis SIL 7.000, the font in which all the IPA of the site is shown.

Designed by SIL Global (https://software.sil.org/charis/), distributed under the SIL Open Font License 1.1 (OFL.txt, in this folder).
The four web files (WOFF2) are the ones of the official release, unmodified:
  Charis-Regular.woff2   Charis-Italic.woff2   Charis-Bold.woff2   Charis-BoldItalic.woff2

The site loads them from style.css (see "Charis SIL"). To use a newer version, replace these four files by those of the new release.
